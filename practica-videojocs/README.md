# ProjecteFinal1rDAW

## DOCKER, JS, HTML, CSS, MySQL

1. Aixecar el Docker:
    1.1 Obrir la terminal
    1.2 Fer cd fins a la carpeta practica-videojocs (important fer-hi cd a dins tambe)
    1.3 executar el comandament "docker compose up -d"
2. Importar practicavideojocs.sql a php
    2.1 Aixi com he configurat el Docker, toca funcionar automaticament
    2.2 En cas d'aver cap errada accedir a l'url http://localhost:8083
    2.3 Entrar amb l'usuari daw i el password iesmanacor
    2.4 Seleccionar la bd practicavideojocs a la barra esquerra un cop dins el php
    2.5 Anar a la pestanya Import de php, seleccionar archivo, seleccionem l'archiu practicavideojocs.sql
    2.6 Baixem i prenem Import, podem desplegar les taules amb el + que apareix a l'esquerra de la BD per veure que ha funcionat
3. URLs per accedir al projecte
    3.1 Frontend: http://localhost
    3.2 Backend: http://localhost:3000/daw/'sentencia SQL a executar'
    3.3 Gestor de la BD (phpMyAdmin): http://localhost:8083
